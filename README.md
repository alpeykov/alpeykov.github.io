# alpeykov.github.io

Holds `.well-known/assetlinks.json` (Digital Asset Links), which lets the Android app
**Gas Consumption** (`io.github.alpeykov.gasconsumption`) open
https://alpeykov.github.io/gas-consumption/ full-screen as a Trusted Web Activity.

The app itself lives in [alpeykov/gas-consumption](https://github.com/alpeykov/gas-consumption).
